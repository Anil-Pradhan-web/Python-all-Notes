# Q10. Advanced Social Authentication System

## Feature Implemented:
Multi-provider social login using:
* Google
* GitHub

## Step 1: Add GitHub Backend (`settings.py`)
```python
AUTHENTICATION_BACKENDS = [
    'social_core.backends.google.GoogleOAuth2',
    'social_core.backends.github.GithubOAuth2',
    'django.contrib.auth.backends.ModelBackend',
]
```

## Step 2: Add GitHub Credentials (`settings.py`)
```python
SOCIAL_AUTH_GITHUB_KEY = os.getenv(
    'GITHUB_KEY'
)

SOCIAL_AUTH_GITHUB_SECRET = os.getenv(
    'GITHUB_SECRET'
)
```

## Output
```text
Users can login using:
- Google
- GitHub

Advanced authentication workflow implemented
```
