# Q5. HTTPS Configuration

## Step 1: Install Packages
```bash
pip install django-extensions
pip install Werkzeug
pip install pyOpenSSL
```

## Step 2: Add django_extensions (`settings.py`)
```python
INSTALLED_APPS = [
    ...
    'django_extensions',
]
```

## Step 3: Configure Hosts (`settings.py`)
```python
ALLOWED_HOSTS = [
    'localhost',
    '127.0.0.1'
]
```

## Step 4: Run HTTPS Server
```bash
python manage.py runserver_plus --cert-file cert.crt
```

## Output
```text
HTTPS development server running successfully
```
