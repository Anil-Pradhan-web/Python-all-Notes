# Q4. Install Python Social Auth

## Step 1: Install Package
```bash
pip install social-auth-app-django
```

## Step 2: Add in INSTALLED_APPS (`settings.py`)
```python
INSTALLED_APPS = [
    ...
    'social_django',
]
```

## Step 3: Add URL Patterns (`urls.py`)
```python
path(
    'social-auth/',
    include('social_django.urls', namespace='social')
),
```

## Output
```text
Social authentication URLs configured successfully
```
