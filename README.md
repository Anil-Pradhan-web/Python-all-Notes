## 🚀 What's Inside?

### 🟢 Python Basics (CSW1)
10 assignments covering Python fundamentals — syntax, data structures, loops, functions, OOP, file handling, and more.

### 🌐 Django Framework (CSW2)
7 assignments + exam prep covering Django ORM, views, templates, authentication, and REST APIs.

### ⚡ FastAPI — Complete Backend Guide
A structured 16-chapter guide (Hinglish) from **basics to production-level** backend development:
| Level | Topics |
|-------|--------|
| 🟢 Beginner | Path Ops, Params, Pydantic, Swagger/OpenAPI |
| 🟡 Intermediate | DI, Middleware, DB (SQLAlchemy), Auth (JWT/OAuth2), Security, Testing, Project Structure |
| 🔴 Advanced | Async, WebSockets, LLM Integration, Performance, Production Practices, CI/CD |
| 💡 Bonus | Backend in AI Era |

📖 **21-Day Study Plan** included in `FASTAPI/STUDY_PLAN_21_DAYS.md`

### 🔄 Git & GitHub
3-part crash course on version control — commits, branching, merging, collaboration workflows.

### 📘 Python Notes
Comprehensive 13-module notes covering everything from Python basics to DSA, projects, and backend essentials.
