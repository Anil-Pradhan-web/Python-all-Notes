# Q9. secureAuthProject

## Step 1: Create Project
```bash
django-admin startproject secureAuthProject
cd secureAuthProject
python manage.py startapp secureAuthApp
```

## Step 2: Install dotenv
```bash
pip install python-dotenv
```

## Step 3: Create .env File (`.env`)
```env
SECRET_KEY=mysecretkey
GOOGLE_KEY=mygooglekey
GOOGLE_SECRET=mygooglesecret
```

## Step 4: Load Environment Variables (`settings.py`)
```python
from dotenv import load_dotenv
import os

load_dotenv()

SECRET_KEY = os.getenv('SECRET_KEY')
```

## Output
```text
Secure authentication project configured successfully
```
