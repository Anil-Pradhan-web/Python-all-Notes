# Assignment 7: The Random Module 🎲 (Probability)

Bhai, is assignment mein tumne game programming, testing, ya simulations ke liye data randomize karna seekha ha. Data Science mein probablity yahi se initiate hoti ha:

1. **`import random`:**
   - Bhai yeh ek inbuilt library function h jise bulakar random events process ho pate hai. Python environment khud hi pseudorandom events setup kardega is module load ke baad.

2. **The Magic of `random.choice([...])`:**
   - Tum is function ko ek sequence pass karoge `["H", "T"]` yani ki lists, tuples of events... Fir yeh automatically bina partiality kiye fair randomness apply karke koi bhi ek object output return pick up kardega! Yahan coin toss ki flip 1000 loop iteration tak process ho raha h.

3. **Probability Formula applied Programatically:**
   - Total chances `(Heads + Tails)` mai se frequency verify horahi . Output run karte dekoge ki ratio around ~0.5 print karega (Yani ke exactly 50/50 unbiased probability). Program math aur theories ke proof ko clearly valid execute karti hui dikhti h yaha par.
