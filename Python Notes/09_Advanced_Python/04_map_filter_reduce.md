# Map, Filter, Reduce — Functional Tools

## Simple Explanation (Hinglish)
Yeh teen functions list/data ke saath loops ke bina kaam karte hain:
- **map**: Har element pe function apply karo
- **filter**: Condition true wale elements lo
- **reduce**: Sabko combine karke ek value do (sum, product)


## Practice Questions (Sirf 5 -- Concept Clear Karne Wale)

1. **(Basic)** map() se list of strings ko uppercase mein convert karo.
2. **(Basic)** filter() se positive numbers nikaalo [-5,3,-2,7,0,-1,4] se.
3. **(Medium)** reduce() se [1,2,3,4,5] ka product nikaalo.
4. **(Medium)** Even numbers filter karo, squares nikaalo using map.
5. **(Hard)** Odd numbers filter karo, square karo, sum nikaalo using reduce.
